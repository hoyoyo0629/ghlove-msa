# order 서비스 AS-IS 전수 대조 (parity audit)

> **문서 목적/독자**: AS-IS "서비스로직도 화면단도 똑같이" 재현 전수 갭 목록. 방식 `[[as-is-parity-exhaustive-audit-method]]`. 작성 2026-09-21.
>
> **기존 문서 활용**: `docs/as-is-feature-audit-order.md`(전수 기능감사), `docs/order-service-analysis-2026-09-10.md`, `docs/cart-review-2026-09-09.md`(장바구니 결함), `docs/order-multiitem-redesign-plan.md`(멀티아이템 재설계). 이 문서는 이들을 order parity audit로 통합한다.

## 1. 최대 구조 갭 — 멀티아이템 주문 (최우선)

**1주문=1답례품(현행) vs AS-IS 1주문=여러 답례품(주문→출고→품목).** 이게 order 최대 갭이고 클레임·주문상세·주문목록·SAGA·정산에 전부 파급된다.
- 상세 설계·근거·Phase 계획: `docs/order-multiitem-redesign-plan.md`, 결정 `[[order-single-item-vs-multiitem-decision]]`.
- **RFP/ISP 요건 아님(구현 단순화)** → 멀티아이템 재설계로 방향 결정. **대공사라 설계안 리뷰 후 Phase 1부터 착수.**

## 2. 주문/배송/클레임 검증 로직 — **상당수 O**

MSA `OrderService`/`ClaimService`에 풍부한 검증이 이미 구현됨:

| 영역 | AS-IS 동작 | MSA | 상태 |
|---|---|---|---|
| 구매확정 | 배송완료 상태만·본인주문·중복확정 방지 | "배송완료 상태인 주문만…", "본인 주문만…", "이미 구매확정된 주문" | **O** |
| 반품/교환 | 배송완료 후·반품가능상품만 | "배송완료된 주문만…", "이 답례품은 교환·반품이 불가합니다" | **O** |
| 주문취소 | 발송 후 취소불가(반품/교환 안내) | "이미 발송된 주문은 취소할 수 없습니다…" | **O** |
| 배송지변경 | 발송 전만·본인 | "이미 발송된 주문은 배송지를 변경할 수 없습니다", "본인 주문만…" | **O** |
| 쿠폰 | 미발행/사용불가/중복사용 차단 | "발행되지 않은 쿠폰", "같은 쿠폰을 여러 답례품에…" | **O** |
| 옵션 | 옵션 선택·소속·품절 | "선택한 옵션이 이 답례품의 옵션이 아닙니다"(이번 세션) | **부분** |
| 장바구니 | 재고·상한·품절 자동제거 | `cart-review-2026-09-09.md` 심각결함 2건 수정 | **O(잔여 §4)** |

## 3. 이번 세션(2026-09-21) 델타

| 항목 | 현재 |
|---|---|
| **주문상세 화면 AS-IS 레이아웃** | 재현 완료 — 주문번호/일자·지자체그룹·답례품카드·배송지정보·결제정보(주문/취소/총 포인트). 단 **단일아이템 기준**(멀티아이템은 §1 재설계 대기) |

## 4. 남은/축소 항목

- **배송비 정책**(출고지/기본/무료기준/도서산간) — gift 감사에도 있음, order 배송비 계산 로직 미비(`as-is-feature-audit-order.md` 참조). 
- **PG/세외수입 결제창** — 외부연계 미개방 축소(`enabled:false`). "결제완료 처리" 버튼으로 대체.
- 클레임 상세(회수/재발송 등) 세부 — `as-is-feature-audit-order.md` 참조.

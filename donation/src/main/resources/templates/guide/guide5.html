오프라인 기부방법

농협 기부안내

01. 오프라인 기부는 농협은행에서 기부가 가능합니다.

기부는 농협은행 창구에서 접수를 진행하고 있습니다.

기부는 자치단체에 기부하기와 특정사업에 기부하기 두가지 방식이 있습니다.

02. 농협은행에서 제공하는 기탁서를 수령하세요

03. 기탁서 제출 및 기부금 수납

작성하신 기탁서와 기부금을 제출해주세요

04. 납부신청서 수령

기탁서와 기부금액을 제출 하시면 은행 창구에서 납부신청서(기부자용)를 제공해드립니다.

고향사랑e음 로그인

01. 고향사랑e음에 접속 합니다. 접속 주소 : https://ilovegohyang.go.kr

02. 아이디ㆍ비밀번호 찾기 버튼을 클릭 해주세요

03. 비밀번호 찾기 버튼을 클릭 해주세요

04. 기부자님 성명과 납부청구서에 기재된 아이디를 입력해주세요

05. 금융인증서, 휴대폰 중 한가지를 사용하여 인증을 진행해 주세요

06. 인증이 완료 되시면 새로운 비밀번호를 설정 하실 수 있습니다.

입력하기 항목에 새로운 비밀번호를 위아래 동일하게 작성 하시고 확인을 클릭해 주세요

07. 비밀번호 설정이 완료 되었습니다.

변경된 비밀번호로 고향사랑e음에 로그인 해주세요

01. 고향사랑e음에 접속 합니다.

접속 주소 : https://ilovegohyang.go.kr

02. 아이디ㆍ비밀번호 찾기 버튼을 클릭 해주세요

03. 비밀번호 찾기 버튼을 클릭 해주세요

04. 기부자님 성명과 납부청구서에 기재된 아이디를 입력해주세요

05. 금융인증서, 휴대폰, 공동인증서 중 한가지를 사용하여 인증을 진행해 주세요

06. 인증이 완료 되시면 새로운 비밀번호를 설정 하실 수 있습니다. 입력하기 항목에 새로운 비밀번호를 위아래 동일하게 작성 하시고 확인을 클릭해 주세요

07. 비밀번호 설정이 완료 되었습니다.

변경된 비밀번호로 고향사랑e음에 로그인 해주세요

답례품 구매

고향사랑e음에 접속 하신 후 상단 마이페이지 버튼을 클릭 하세요

01. 마이페이지에서 기부하신 지자체 목록을 확인 하실 수 있습니다.

02. 기부포인트 현황을 클릭 하시면 지자체의 포인트를 확인 하실 수 있습니다.

정상 기부내역을 확인 하신 후에 포인트를 확인 하세요

03. 기부하신 지자체의 포인트를 클릭 하시거나 답례품 바로가기 버튼을 클릭 하시면 기부하신 지자체의 답례품을 확인 하실 수 있습니다.

기부하신 지역의 답례품을 확인 하시고 마음에 드시는 상품을 선택 하세요

04. 기부하신 지역의 포인트를 확인 하시고 구매 하세요

고향사랑e음에서는 답례품 선택 시 갖고 계신 한도 내에서 답례품 선택이 가능 합니다.

05. 바로선택 버튼을 클릭 하시면 답례품 신청이 진행 됩니다.

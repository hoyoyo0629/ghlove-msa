회원 배치관리

실시간 스케줄러 없이 운영자가 수동으로 트리거하는 회원 배치 작업입니다 (SFR-002 휴면 전환 / 데이터 파기 절차).

휴면 전환

최근 로그인일이 기준일(기본 365일)보다 오래된 정상 회원을 휴면 상태로 전환합니다.

건이 휴면 전환되었습니다.

데이터 파기 절차

탈퇴 후 보관기간(기본 30일)이 지난 회원의 개인식별정보를 익명화하거나, 보관기간(기본 1년)이 지난 로그인 로그의 접속 IP를 마스킹합니다. 행 자체는 지우지 않고 식별정보만 제거합니다.

로그 건의 IP가 마스킹되었습니다.
